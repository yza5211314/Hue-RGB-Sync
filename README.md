# RGB 灯光同步系统 🎨

这是一个基于 Python 开发的 RGB 灯光同步系统，支持硬件模式切换和屏幕颜色同步功能。

## 核心功能
- **⌨️ 虚拟键盘控制**：支持 MK850 键盘的 104 键独立灯光控制，界面与物理布局完美对齐。
- **🖥️ 屏幕同步**：实时提取屏幕主色调并同步至硬件设备。
- **✨ 硬件模式**：支持切换键盘内置的呼吸、波浪、光谱循环等多种硬件效果。
- **🎮 紧凑控制中心**：集成颜色选择器、滑块、快捷色块与同步控制，界面极简无空白。

## 支持设备
- **Keyboard**: EVision MK850 (VID: 0x0C45, PID: 0x5004)
- **Mouse**: 支持 TSG600 系列

## 快速开始
1. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
2. 运行程序：
   ```bash
   python gui_control.py
   ```

## 注意事项
- 请确保以**管理员权限**运行程序以获得 HID 设备的访问权。
- 运行前请关闭其他可能占用键盘 HID 接口的软件（如 OpenRGB）。
