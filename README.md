# RGB 灯光同步系统 🎨

这是一个基于 Python 开发的专业级 RGB 灯光同步系统，支持全键独立控制、硬件模式切换及屏幕颜色实时同步。

## 核心功能
- **⌨️ 虚拟键盘控制**：支持 MK850 键盘的 **105 键**全键独立灯光控制，界面与物理布局完美对齐。
- **🖥️ 屏幕同步**：实时提取屏幕主色调并同步至硬件设备。
- **✨ 硬件模式**：支持切换键盘内置的呼吸、波浪、光谱循环等多种硬件效果。
- **🎮 紧凑控制中心**：集成颜色选择器、滑块、快捷色块与同步控制，界面极简无空白。
- **📦 自动构建**：集成 GitHub Actions，自动编译生成单文件版 EXE。

## 支持设备
- **Keyboard**: EVision MK850 (VID: 0x0C45, PID: 0x5004)
- **Mouse**: 支持 TSG600 系列

## 快速开始
1. **安装依赖**：
   ```bash
   pip install -r requirements.txt
   ```
2. **启动程序**：
   - 推荐：右键点击 `启动控制面板.bat` -> **以管理员身份运行**
   - 命令行：`python gui_control.py`
 3. **获取 EXE 版本**：
    - 访问项目 GitHub 仓库的 `Actions` 页面，下载最新的 `RGB-Sync-Control-EXE` 构件。

## 注意事项
- 请确保以**管理员权限**运行程序以获得 HID 设备的访问权。
- 运行前请关闭其他可能占用键盘 HID 接口的软件（如 OpenRGB）。
- **防病毒软件提示**：由于程序涉及底层硬件控制且未经过数字签名，部分杀毒软件可能会拦截其 HID 通信。如果设备扫描不到，请尝试将 EXE 加入白名单或暂时关闭防护。
